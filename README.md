# FIT CORE — Telegram-бот

Тренировки, замены упражнений, питание, калькулятор, лог веса, напоминания, фазы цикла, библиотека видео.

## Новое

- **Напоминания** — время и дни недели, часовой пояс `TZ` (по умолчанию `Europe/Moscow`)
- **Лог веса** — запись, история, дельта
- **Замены** — у каждого упражнения 2–3 альтернативы (кнопка под днём)
- **Цикл** — дата старта, длина, фаза дня и совет по нагрузке (не медицина)
- **Видео** — день → упражнение → загрузить ролик или ссылку. Если `ADMIN_IDS` совпал с твоим id, ролик становится общим шаблоном техники

## Запуск

```bash
cd tg_fit_bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# BOT_TOKEN=...  ADMIN_IDS=твой_telegram_id  TZ=Europe/Moscow
python bot.py
```

Свой id: напиши [@userinfobot](https://t.me/userinfobot).  
Чтобы напоминания приходили, процесс `python bot.py` должен жить постоянно.

## Важно

Цикл и гормоны — ориентир, не диагноз. Препараты бот не назначает.
